# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vue 3 + TypeScript + Pinia + Vue Router + Vite，打包为 Tauri 2 桌面应用（Windows）。后端 Express + MySQL + Redis（云端），AI 能力接 DeepSeek。与后端通过 HTTP + Socket.IO 通信。

## Users

- **主要用户**：有心理倾诉/自我探索需求的年轻人（大学生为主），在私人电脑上独处使用，场景是深夜或日常的情绪记录、AI 倾诉、心理自测、预约专家咨询。
- **管理角色**：管理员（内容与用户管理）、心理专家（接诊/预约管理）。本应用为毕业设计作品，评审/答辩观众是重要的"第二观众"。

## Product Purpose

「心愈」是一个桌面端心理健康服务平台：AI 心理咨询（流式对话）、心理测评（量表作答→计分→分级报告）、周期性 AI 分析报告、专家预约与实时私聊。成功意味着使用者感到被倾听、安全、愿意持续使用。

## Positioning

差异化机制：把"AI 陪伴 → 测评 → 报告 → 真人专家"做成一条连续的心理关怀闭环，而非孤立的聊天机器人或量表工具。桌面端形态（非网页套壳）本身即是定位的一部分。

## Operating Context

- 单机窗口应用，自绘标题栏，窗口 1280×820 起。
- 中文界面；界面文案语气需温和、不评判、保护隐私感受。
- 心理健康领域的视觉伦理：避免临床冰冷感，也避免娱乐化；情绪安全优先。

## Capabilities and Constraints

- 已实现：邮箱验证码注册/登录、AI 流式聊天、量表测评与历史、AI 周期报告、专家预约与 Socket.IO 私聊、管理后台、亮/暗/跟随系统三态主题（Vue 主题 class 已接通）。
- 本地会话与配置经 AES-256-GCM 加密落盘（Rust 侧）。
- 约束：桌面窗口固定范围（1024×700 起），无需移动端适配；不做复杂手势。
- 已确认 undecided：无。

## Brand Commitments

- 品牌名「心愈」（拼音 XinYu，应用标识 com.xinyu.heart）必须保留。
- 原 logo（月牙托爱心，淡蓝底）为已确认品牌资产，位于 `src-tauri/icons/icon.ico`，必须保留且不得重绘。
- 界面禁止使用 emoji 作为图标；图标一律使用内联 SVG。

## Evidence on Hand

- 可运行的前端代码与云端后端（部署地址见 `.env.*.local`，健康检查可用）。
- 演示账号：admin@xinyu.local（管理员）。
- 无真实用户见证/运营数据；不得虚构。演示数据可合成但需可辨识。

## Product Principles

1. **情绪安全优先**：任何视觉决策不得制造压迫感、临床冰冷感或评判感。
2. **桌面应用，而非网页**：信息密度、控件质感、窗口行为向原生桌面应用看齐。
3. **品牌连续**：月亮-爱心意象与品牌名贯穿，不因重设计而断裂。
4. **亮暗同等公民**：双主题下对比度、氛围、层次都必须成立。
5. **内容即界面**：对话、测评、报告是主角，界面退后。

## Accessibility & Inclusion

- 中文正文可读性优先；对比度满足 WCAG AA。
- 心理健康语境：错误与空状态文案需温和、去污名化。
