## 简介 / Overview

**中文**

一个桌面端心理健康服务平台：AI 心理咨询（流式对话）、心理测评（量表作答 → 自动计分 → 分级报告）、周期性 AI 分析报告、专家预约与实时私聊。

定位是把「AI 陪伴 → 测评 → 报告 → 真人专家」做成一条连续的心理关怀闭环，而非孤立的聊天机器人或量表工具。

**English**

A desktop mental-health service platform: AI psychological counseling (streaming chat), psychological assessment (questionnaire -> auto scoring -> tiered report), periodic AI analysis reports, expert booking and real-time private chat.

The positioning is to turn "AI companionship -> assessment -> report -> human expert" into one continuous mental-health care loop, rather than an isolated chatbot or questionnaire tool.

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌──────────────┐
│  AI 倾诉陪伴 │ --> │  心理测评     │ --> │ 周期分析报告 │ --> │  专家预约私聊 │
│  DeepSeek   │     │  计分+分级    │     │  趋势洞察    │     │  Socket.IO   │
└─────────────┘     └──────────────┘     └─────────────┘     └──────────────┘
```

## 功能特性 / Features

### 用户端 / Client (user)

**中文**

- **AI 心理咨询**：基于 DeepSeek 的流式对话，温和、不评判的倾诉空间
- **AI 智能测评**：固定置顶的个性化测评入口，题目由 AI 实时生成（每次内容不同），作答后由 AI 综合评分（0-100）并输出分级解读与建议；生成的问卷与作答明细完整入库，专家端可查看完整的「问题 + 选项 + 用户选择」
- **心理测评**：量表作答、自动计分、分级报告与历史记录；管理员可在后台维护量表题库
- **AI 周期报告**：基于倾诉与测评数据的周期性心理健康分析，报告以结构化文档排版呈现（章节、列表、重点标注），支持复制纯文本或导出为排版精美的 HTML 文件
- **专家预约与私聊**：预约心理专家，Socket.IO 实时私聊（多设备在线状态、消息已读、离线通知、双方头像展示）；用户与专家均可取消/拒绝预约，状态变更实时同步；同一用户对同一专家不可重复预约
- **聊天举报**：聊天内可勾选对方的一条或多条消息提交举报（辱骂攻击 / 骚扰 / 广告推销 / 色情低俗 / 其他，附补充说明），由管理员在后台核实处置
- **专家卡片列表**：专家以卡片网格展示，含头像、职称、擅长方向、简介与实时在线状态，悬停浮起交互；管理员上/下架专家名片后，所有在线用户的专家列表即时自动刷新

**English**

- **AI counseling**: streaming dialogue backed by DeepSeek, a gentle and non-judgmental space to open up
- **AI smart assessment**: a fixed, pinned personalized assessment entry; questions are generated by AI in real time (different each time), and after answering, AI scores holistically (0-100) and outputs a tiered interpretation with suggestions; the generated questionnaire and every answer are fully stored and visible to experts as complete "question + options + user choice"
- **Psychological assessment**: questionnaire answering, auto scoring, tiered reports and history; admins can maintain the item bank from the backend
- **Periodic AI reports**: periodic mental-health analysis based on venting and assessment data, rendered as a structured document (sections, lists, highlights), with copy-as-plain-text or export to a well-formatted HTML file
- **Expert booking & private chat**: book a psychology expert and chat in real time over Socket.IO (multi-device online status, read receipts, offline notifications, both avatars); either side can cancel/reject a booking with status synced in real time; a user cannot double-book the same expert
- **Chat reporting**: within a chat, select one or more of the other party's messages to submit a report (abuse/attack / harassment / advertising / pornographic/vulgar / other, with a free-text note), verified and handled by admins in the backend
- **Expert card list**: experts shown as a card grid with avatar, title, areas of expertise, intro and live online status, with a hover-lift interaction; when an admin lists or unlists an expert's card, the expert list auto-refreshes instantly for all online users

### 专家端 / Expert

**中文**

- **专家名片审核**：在「我的名片」编辑姓名、职称、专长与简介并提交审核，管理员通过后名片才显示在专家列表
- **预约管理**：查看来自用户的预约，确认或拒绝，拒绝后用户可重新预约
- **咨询私聊**：与预约用户一对一实时沟通，双方头像展示；内置「敏感词库 + AI 语义复核」双层内容审核，侮辱、淫秽及谐音/拆字/缩写等变体自动拦截，AI 结合最近聊天上下文识别隐晦骚扰，复核服务异常时宁可错拦不可放过；发送前先做本地预检，命中敏感词即时标红提示，不发出才拦截

**English**

- **Card review**: edit name, title, specialties and intro under "My Card" and submit for review; the card only appears in the expert list after admin approval
- **Booking management**: view bookings from users, confirm or reject; after rejection the user can rebook
- **Consultation chat**: one-to-one real-time communication with the booked user, both avatars shown; a two-layer "sensitive-word list + AI semantic re-check" content review is built in - insults, obscenity and homophone/character-splitting/abbreviation variants are auto-blocked, AI uses recent chat context to detect subtle harassment, and when the re-check service is unavailable it errs on blocking; a local pre-check runs before sending, flagging sensitive words in red instantly so offending messages are blocked before they go out

### 管理端 / Admin

**中文**

- **管理后台**：用户与预约的增、删、改、查（删除用户连带清理关联数据）
- **举报管理**：接收聊天举报并核查，可对被举报账号实施实时禁言 / 封禁（可选 24 小时 / 72 小时 / 7 天 / 永久，封禁立即踢下线、禁言即时拦截发言，到期自动解除），也支持驳回举报与随时解除限制；用户管理页展示账号状态
- **名片审核**：专家名片通过上架 / 拒绝下架
- **敏感词库**：可视化维护聊天审核词库（分类、短词匹配标记），增删实时生效，无需重启服务
- **量表管理**：心理测评的题库维护
- **万能钥匙**：管理员凭密码可解锁任意锁屏会话（服务端验证后为原账户换发凭据）

**English**

- **Console**: create, read, update and delete users and bookings (deleting a user also cleans up related data)
- **Report handling**: receive and review chat reports, apply real-time muting/banning to the reported account (optional 24h / 72h / 7 days / permanent; a ban disconnects immediately, a mute blocks speech instantly, both auto-expire), and also dismiss reports or lift restrictions at any time; the user management page shows account status
- **Card review**: approve/list or reject/unlist expert cards
- **Word list**: visually maintain the chat review word bank (categories, short-word match flags); add/remove takes effect live with no service restart
- **Item bank**: maintain the psychological assessment question bank
- **Master key**: an admin can unlock any locked session with a password (after server-side verification, credentials are reissued for the original account)

**中文**

- **桌面集成**：系统托盘（QQ 式：后台有未读时托盘图标叠加红色数字角标，整个图标不透明/透明交替频闪；鼠标悬浮托盘图标弹出消息卡片小窗，展示发送者头像、内容摘要与未读数，界面跟随应用明暗主题，点击卡片直达对应聊天；左键单击显示/隐藏窗口开关）、关闭行为设置（询问 / 最小化到托盘 / 直接退出）、全局快捷键 `Ctrl+Alt+H` 一键呼出/隐藏、系统通知

- **主题系统**：亮 / 暗 / 跟随系统三态主题
- **自动检查更新**：启动静默检查 + 设置页手动检查；Gitee 与 GitHub 双更新源并发查询、自动容灾，任一源不可达时切换另一源并取可达源中的最高版本；发现新版由用户决定是否下载，下载过程显示实时进度条并支持随时取消，完成后一键安装（退出程序并唤起安装向导）
- **WebView2 引导**：安装时检测 WebView2 运行时（机器级/用户级、64/32 位视图全覆盖），缺失时弹窗询问是否联网安装，拒绝则中止安装并给出官方手动安装指引

**English**

- **Desktop integration**: system tray (QQ-style: when there are unread background messages the tray icon overlays a red count badge and blinks between opaque/transparent; hovering the tray icon pops a message card showing sender avatar, content summary and unread count, following the app's light/dark theme, click the card to jump straight to that chat; left-click toggles the window), close-behavior setting (ask / minimize to tray / quit directly), global shortcut `Ctrl+Alt+H` to summon/hide, and system notifications
- **Background message alerts**: when a private message arrives while the window is minimized/hidden/unfocused, a system notification-center popup (visible even when hidden to the tray) + orange taskbar icon blink + title message preview + taskbar hover thumbnail turning into a message card (sender, content summary and unread count, drawn via the DWM icon bitmap); clicking the taskbar icon, thumbnail or tray card returns to the window and jumps straight to the chat, and one message alerts only once no matter how many delivery paths it takes
- **Shortcut blocking**: automatically blocks browser-style shortcuts (mouse side buttons forward/back, F5 refresh, Ctrl+scroll zoom, Alt+arrow navigation, etc.) to prevent mis-taps or bypassing the app flow
- **Theme system**: light / dark / follow-system, three states
- **Auto update check**: silent check on launch + manual check in settings; concurrent queries against Gitee and GitHub dual update sources with automatic failover, switching to the reachable source and taking the highest version among reachable ones; on a new version the user decides whether to download, with a real-time progress bar and cancellation, then one-click install (exit the app and launch the installer)
- **WebView2 bootstrapping**: detects the WebView2 runtime during install (machine/user level, 64/32-bit views all covered); if missing, asks whether to install online, otherwise aborts the install and provides official manual-install instructions

### 安全设计 / Security design

**中文**

- **本地数据加密**：会话与配置经 AES-256-GCM 加密落盘（Rust 侧），密钥编译进二进制
- **会话安全**：JWT + Redis 会话映射，支持单点登录（新登录顶掉旧会话）；登出 / 锁屏即服务端真注销（token 黑名单），被截获的旧凭据无法复用
- **锁屏保护**：一键锁定 / 离开自动锁定（仅登录后生效）；锁屏状态跨重启保持；解锁须凭账户密码或管理员万能钥匙
- **接口权限**：角色分级（用户 / 专家 / 管理员），管理与专家接口双重校验；聊天记录读取、发送与实时房间加入均做预约归属校验，无关账号无法越权访问他人会话
- **参数可信**：消息收发双方由服务端按预约关系推导，不信任客户端传入的身份字段

**English**

- **Local data encryption**: sessions and config are encrypted at rest via AES-256-GCM (on the Rust side), with the key compiled into the binary
- **Session security**: JWT + Redis session mapping with single sign-on (a new login kicks out the old session); logout/lock performs a true server-side revoke (token blacklist), so intercepted stale credentials cannot be reused
- **Lock protection**: one-click lock / auto-lock on leaving (effective only after login); lock state persists across restarts; unlocking requires the account password or the admin master key
- **Endpoint authorization**: role tiers (user / expert / admin), with double checks on admin and expert endpoints; reading chat, sending, and joining the realtime room all validate booking ownership, so unrelated accounts cannot access someone else's conversation
- **Trusted parameters**: the sender and receiver of each message are derived server-side from the booking relationship; client-supplied identity fields are never trusted

## 快速开始 / Quick Start

### 环境要求 / Requirements

- Node.js >= 18
- MySQL >= 8
- Redis
- Rust + WebView2（仅 Tauri 桌面端构建需要 / only needed to build the Tauri desktop client）

### 1. 初始化数据库 / Initialize the database

```bash
mysql -u root -p < backend/db/schema.sql
```

脚本会创建全部数据表并内置一个示例量表（情绪自评，PHQ-9 简化版），管理员账号需手动插入（`role = 3`）。
The script creates all tables and seeds one sample test (mood self-assessment, a simplified PHQ-9). The admin account must be inserted manually (`role = 3`).

### 2. 配置并启动后端 / Configure and start the backend

在 `backend/` 下创建 `.env`（参考下方环境变量），然后： / Create `.env` under `backend/` (refer to the environment variables below), then:

```bash
cd backend
npm install
npm run dev        # 开发模式 dev mode (tsx watch)，默认端口 default port 3001
```

生产部署 / Production deploy:

```bash
npm run build
npm start          # 运行 runs dist/index.js
```

### 3. 启动前端 / Start the frontend

```bash
cd frontend
npm install
npm run dev          # 浏览器开发预览 browser dev preview (Vite)
npm run tauri:dev    # 桌面端开发模式 desktop dev mode
npm run tauri:build  # 打包 Windows 桌面应用 package the Windows desktop app (产出 outputs target/release/心愈.exe)
```

前端通过 `.env.development` / `.env.production` 中的 `VITE_API_BASE`、`VITE_SOCKET_URL` 指向后端地址，修改即可，无需改代码。
The frontend points at the backend via `VITE_API_BASE` and `VITE_SOCKET_URL` in `.env.development` / `.env.production`; edit those, no code change needed.

### 4. 打包安装程序 / Package the installer (Inno Setup)

```bash
# 先执行 Run npm run tauri:build 产出主程序 to produce the main executable, then 再运行 run:
"C:\Program Files\Inno Setup 7\ISCC.exe" frontend\src-tauri\windows\xinyu.iss
# 产物 Output: frontend\src-tauri\target\release\bundle\inno\心愈_<版本 version>_x64-setup.exe
```
